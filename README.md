# ETL Project

A practical ETL pipeline built with **Python and Pandas** to process and transform e-commerce data.

The project works with three datasets:

* Customers
* Products
* Orders

The pipeline extracts raw CSV files, cleans and validates the data, transforms and merges the datasets, calculates `total_amount`, and loads the final result into a CSV file.

```text
Raw CSV Data
     ↓
Extract
     ↓
Clean
     ↓
Transform
     ↓
Load
     ↓
Final Dataset
```

The project was built to practice real-world **Data Engineering and ETL concepts**, including data cleaning, transformation, validation, logging, and modular pipeline design.
